## 常逛的站

- **[Hexo 官方文档](https://hexo.io/zh-cn/docs/)** — 本站的地基，配置项查这里最准
- **[Butterfly 主题文档](https://butterfly.js.org/)** — 主题所有配置项的说明，改样式先翻它
- **[PortSwigger Web Security Academy](https://portswigger.net/web-security)** — 免费的 Web 安全实验，从入门到进阶都有
- **[TryHackMe](https://tryhackme.com/)** — 引导式的渗透练习房间
- **[Hack The Box](https://www.hackthebox.com/)** — 靶机多，难度偏高
- **[MITRE ATT&CK](https://attack.mitre.org/)** — 攻击技战术知识库，写报告引用很合适
